# Lumen

Camera tools, aiming assistance, and customizable visuals for Multicrew Tank Combat.

## Load

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/eduardonash/attribute/main/lumen.lua"))()
```

## Usage

Use the in-game menu to toggle features and customize visuals, distances, and keybinds. **Trajectory → Shell ESP** controls your shell visuals.

`lumen.lua` is the current release. Use only in experiences where you have permission, and follow the experience's rules.
