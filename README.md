# attribute

Source repository for the AutoLeadAssist Luau project.

- `attribute.lua` — current script
- `PROJECT.md` — architecture, controls, limitations, and verification notes

Player ESP uses a commit-pinned [fork of tulontop/esp-lib.lua](https://github.com/eduardonash/esp-lib.lua), authored by tul (@.lutyeh), with corrected full-body bounds and managed cleanup. Tank ESP retains Roblox Highlights. See `PROJECT.md` for test status and limitations; the previously reported executor disconnect remains unresolved.
